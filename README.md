# World Astronomical Clock

Interactive educational astronomical clock inspired by the Prague Orloj.

## Publish with GitHub Pages

Upload these extracted files directly to the root of a public repository named `world-astronomical-clock` (do not upload the ZIP itself). Include the vendor and utils folders.

In Settings > Pages, choose Deploy from a branch, branch main, folder / (root), and Save.
Test the generated github.io address before changing DNS.

After testing, verify ownership of WorldAstronomicalClock.com, set it as the custom domain in Pages, and configure the domain DNS at GoDaddy according to GitHub Pages documentation. Enable Enforce HTTPS when the certificate is ready. Configure www as well if desired. Keep unrelated DNS records unchanged.

Share This Moment uses the current website address. Test a shared moment, About, model loading, and Use my location over HTTPS before switching the domain.

This package contains all runtime files. No build step or IIS configuration is required. Third-party vendor software retains its existing license notices.
